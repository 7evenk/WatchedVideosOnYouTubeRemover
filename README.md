# Watched Videos On YouTube Remover

Chrome-Erweiterung, Manifest V3. In chrome://extensions den Entwicklermodus einschalten und **Entpackte Erweiterung laden → extension** wählen. Danach die Zielseite neu laden.

Node.js 24+: npm test, npm run check, npm run build. ZIPs und versionierte entpackte Pakete liegen in dist/. [Einheitlicher Aufbau und Umstellung](docs/extension-layout.md).

Funktionen, Berechtigungen und Versionsnummer bleiben unverändert. Keine Store-Veröffentlichung durch diese Umstellung.
